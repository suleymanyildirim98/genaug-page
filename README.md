# GenAug project page

Public, static research-preview page for GenAug. This repository deliberately
contains only website assets; source code and experimental artifacts remain in
the private `genaug` repository.

Publish this repository as `suleymanyildirim98/genaug-page`. Configure GitHub
Pages to deploy from the `main` branch and the repository root. The site URL
will be `https://suleymanyildirim98.github.io/genaug-page/`.
